# Pilot economics: sensitivity and capacity

These are arithmetic sensitivities, not measured usage. They supplement the approved default; no price, allowance or default forecast input was changed. Plans are introductory pilot prices, subject to measured delivery cost and customer-value validation.

## Full included usage

Founder: $49.99, 7 assessments, 1M assessed lines. Growth: $129.99, 20 assessments, 5M lines. Scale: $359.99, 60 assessments, 20M lines. Both run and line pools apply across repositories; repeated assessments count lines again.

With supplied API $1.90/run, planned sandbox $1/run, AWS $7/account, support/storage $5/$12/$30 and payments 2.9% + $0.30, monthly variable costs are $34.04971 / $81.06971 / $221.73971. Contributions before $500 shared tools and excluded labor/acquisition are $15.94029 / $48.92029 / $138.25029 (31.9% / 37.6% / 38.4%). This is not full-business profit.

## Larger repositories or retries

Stress assumption: API and sandbox costs per included assessment double, with other inputs unchanged. Variable costs become $54.34971 / $139.06971 / $395.73971; contribution becomes −$4.35971 / −$9.07971 / −$35.74971. All three turn negative at full allowance. This is a deliberately simple sensitivity, not a claim that larger repositories cost exactly twice as much. Token volume, repeated tool calls, runtime and stored evidence require measurement.

## Founder support time

Additional support beyond the existing allowance: assumed 30 minutes/account/month valued at an illustrative $30/hour adds $15/account. Contributions become $0.94029 / $33.92029 / $123.25029. Founder would need 532 whole active paying accounts to cover $500 shared tools on this economic-cost basis. The $30 rate is a planning sensitivity, not a salary, hire or market wage claim. If unpaid, it remains an economic cost rather than an immediate cash payment. Record minutes even when no salary is paid; avoid double-counting support already allocated.

Combining doubled API/sandbox with that additional $15 support produces negative contributions of −$19.35971 / −$24.07971 / −$50.74971. Do not expand a loss-making usage promise.

## Approved forecast and validation

The canonical model retains 42 new paid/month from M2, 18.2% initial opt-in-trial proxy and 2% assumed churn. It proposes 50 free pilot workspaces in M1 for usage data and feedback, then no new free pilots from M2. Under full-use assumptions this costs $2,115 in M1 including shared tools. Monthly cash coverage is conditional in M2; cumulative recovery is M4, with a 32-account Founder threshold under default paid-account costs. Acquisition labor, founder pay, taxes/legal and extra usage are excluded. $500 shared tools is separate from customer delivery. Lower acquisition or higher costs can move or remove crossings; the timing is not guaranteed. See `pilot-plan.md` for consent, capacity and measurement gates.

Use `pilot-cost-measurement.csv` for billed API/token usage, size, runtime, retries, storage, AWS allocation and support. Reconcile overlapping cost buckets. Expansion gate: positive observed contribution at promised allowance, acceptable reliability, understood permissions and measured channel/support capacity. If unmet, cap scope or reprice. See `pilot-plan.md` for the 42/month acquisition workload.
