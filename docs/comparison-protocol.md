# Evidence-ready comparison reference

Status: planned protocol. No Ari-versus-competitor benchmark runs or wins are supplied. The nine-competitor map is sourced qualitative positioning only.

Use the same human-authorized repository, pinned commit, scenario and resource boundaries where a tool supports them. Record incompatible scope as not comparable, never as a failure. Compare commercial editions and enabled features explicitly; do not equate one SAST scan with a bounded multi-agent assessment or infrastructure pentest.

For each run record: date, operator, authorization, tool/version/edition/configuration, repository SHA, supported languages, scenario/expected behavior, seeded versus naturally occurring issue, provider mode, input context, actual tests performed, budget, raw findings, usefulness/adjudicator, reproducibility evidence, repair proposal, independent verification, existing tests, false/inconclusive/error outcomes, elapsed time, billed cost, support minutes and immutable artifact links.

Have a reviewer independent of patch authorship adjudicate usefulness and repair behavior. Retain missed findings, tool failures, unsupported cases and manual intervention. Repeat comparable scenarios, report denominators and variance, and distinguish published vendor claims from observed results. No numerical ranking or coordinate should be added until these records exist.
